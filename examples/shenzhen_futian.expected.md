# Shenzhen Futian — Expected Output Shape

## 用户需求

- 城市：深圳
- 区域：福田区
- 活动片区：领展中心城 / 会展中心 / COCO Park
- 人数：4–6 人
- 距离：3.0–4.5 km
- 便利店：10–14 家
- 终点偏好：COCO Park 酒吧街

## 候选路线

### A — CBD 环线 / 精致夜景线
- 约 3.6 km
- 约 50–70 min
- 约 12–14 checkpoints
- 特点：道路清晰、CBD 夜景、适合第一次组织
- 推荐指数：最高

### B — 社区挑战线
- 约 4.0–4.5 km
- checkpoint 更密
- 特点：街区变化大、趣味性更强
- 适合：希望更有节目效果的团队

### C — 主干道简单线
- 约 3.5–4.0 km
- 特点：少转弯、导航容易
- 适合：不熟悉当地道路的团队

## 推荐路线

推荐 A。

理由：
1. 距离命中需求。
2. 便利店数量适中。
3. 地标清晰，方向感强。
4. 最终落在 COCO Park 夜生活区域。
5. 最适合作为 Skill 的基准回归案例。
